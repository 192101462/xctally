# xctally · 设计规范 v0.1

> 风格目标：**简约、圆滑、克制**。参考 Apple / iOS 的视觉语言，但只借"结构"不抄"装饰"——
> 大圆角、大留白、极轻阴影、系统字体、数字等宽，颜色只在关键处用力。

配色以 iOS 系统色为基准，浅深两套，全部走 CSS 变量，换肤只改一份。

---

## 1. 颜色

### 浅色

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F2F2F7` | 页面底色（iOS systemGroupedBackground） |
| `--card` | `#FFFFFF` | 卡片 |
| `--label` | `#1C1C1E` | 主文字 |
| `--label-2` | `rgba(60,60,67,.62)` | 次级文字 |
| `--label-3` | `rgba(60,60,67,.36)` | 三级文字 / 占位符 |
| `--hairline` | `rgba(60,60,67,.12)` | 发丝分隔线 |
| `--fill` | `rgba(120,120,128,.12)` | 输入框 / 胶囊底 |

### 强调色（只在关键数字与操作上出现）

| 变量 | 值 | 语义 |
|---|---|---|
| `--blue` | `#007AFF` | 主操作、数据主体（持有成本曲线） |
| `--green` | `#34C759` | 安全 / 充足 |
| `--orange` | `#FF9500` | 注意 / 上升 |
| `--red` | `#FF3B30` | 过期 / 浪费（首页唯一的大红色数字） |
| `--purple` | `#5856D6` | 辅助分类 |
| `--teal` | `#30B0C7` | 辅助分类 |

### 深色

`--bg:#000`、`--card:#1C1C1E`、`--label:#F2F2F7`，强调色换成 iOS 深色版
（`#0A84FF / #30D158 / #FF9F0A / #FF453A`），保证暗色下的对比度。

**规则**：一屏之内，饱和色最多出现在 2 个地方（通常是"最重要的数字"和"主要按钮"），
其余一律用灰阶。这是"简约"最容易失守的地方。

## 2. 圆角

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--r-sm` | 12px | 输入框、搜索框 |
| `--r-md` | 16px | 按钮、指标块 |
| `--r-lg` | 22px | 卡片、分组列表 |
| `--r-xl` | 28px | 底部表单面板（只圆上方两角） |
| `--r-pill` | 999px | 胶囊、标签、悬浮按钮 |
| 图标块 | 13px（42px）/ 20px（64px） | 分类 emoji 底板 |

**规则**：圆角半径随容器尺寸递增（嵌套时内层小于外层），避免"大圆角套大圆角"的笨重感。

---

## 3. 字体与排版

字体栈：`-apple-system → SF Pro → PingFang SC → 系统字体`，中文场景优先苹方。

| 层级 | 字号 / 字重 | 说明 |
|---|---|---|
| 页面大标题 | 32px / 700 / `-0.025em` | 只有一屏一个 |
| 卡片主数字 | 40px / 700 / `-0.03em` | 首页"已经浪费掉的钱" |
| 次级数字 | 24px / 700 | 两列小卡 |
| 列表标题 | 15px / 590 | |
| 正文 | 15px / 400 | |
| 次要说明 | 12–13px / 400 | `--label-2` |
| 标签 | 11–12px / 650 | 胶囊 |

**数字必须等宽**：所有金额与天数加 `font-variant-numeric: tabular-nums`，
否则列表里数字跳动、对不齐，一眼就"不精致"。

**负字距**：字号越大越要收紧（大标题 `-0.025em`），这是 Apple 排版的关键细节。

---

## 4. 间距与布局

- 基础间距 4 / 8 / 12 / 16 / 20 / 26
- 页面左右安全边距 **18px**，模块之间 **26px**
- 卡片内边距 18px，列表行内边距 12×14px
- 触摸目标不小于 **44×44**

**分组列表（Apple 的标志性结构）**：一个圆角卡片包裹多行，行与行之间只用 1px 发丝线，
而不是每行一张卡。整屏卡片数量控制在 4–6 个以内。

---

## 5. 阴影与层次

| 变量 | 值 | 用途 |
|---|---|---|
| `--shadow-card` | `0 1px 2px rgba(16,24,40,.04), 0 10px 24px -12px rgba(16,24,40,.16)` | 卡片 |
| `--shadow-float` | `0 6px 20px -6px rgba(0,122,255,.5)` | 悬浮按钮 / 主按钮 |

**规则**：阴影只用来表达"浮起"，且必须有负扩散（`-12px`）让边缘柔和。
深色模式下阴影几乎不可见，改用**卡片底色差**（`#000` vs `#1C1C1E`）表达层次。

---

## 6. 动效

| 场景 | 时长 / 曲线 |
|---|---|
| 面板弹出 | 360ms `cubic-bezier(.22, 1, .36, 1)` |
| 按钮按下 | 120–160ms，缩放至 0.92–0.96 |
| 柱子 / 进度条 | 500ms 同上曲线 |
| 主题切换 | 300ms ease |

**规则**：只用"缓出"曲线，不用弹跳；按下必须即时缩放反馈（这是"跟手"的来源）。

---

## 7. 图标与插画

- 分类用 **emoji + 渐变底片**（浅色渐变，13–20px 圆角），零成本获得彩色而不花哨。
- 底部标签栏用手写的 1.7px 线宽 SVG，靠 `currentColor` 随选中态变蓝。
- 应用图标：蓝色渐变圆角方 + 白色记账卡 + 蓝色衰减曲线 + 橙色端点
  （见 [icon.svg](icon.svg)，曲线就是这个 App 的招牌视觉）。

---

## 8. 文案口吻

- 说人话，不说"数据管理"：写「已经浪费掉的钱」，不写「过期资产统计」。
- 数字要给出解释：`¥38.60` 下面跟一句「3 样东西过期未处置」。
- 空状态给方向，不给情绪：写「暂时没有快到期的东西」，不写「暂无数据」。
